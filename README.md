# SneakerHub (Frontend Client)

SneakerHub is the frontend client of a full-stack MERN e-commerce web application. Built with React and optimized for modern user experiences, it features a responsive interface, dynamic product filtering, interactive wishlists, a seamless shopping cart, and a dedicated administrative dashboard.

> **Note:** This repository contains the standalone Frontend user interface. The Backend API core and database management logic are hosted in a separate repository.

## 🚀 Features

* **Responsive E-Commerce UI:** Fully adaptive, mobile-friendly interface for browsing and buying products.
* **Dynamic Product Catalog:** Real-time filtering and sorting by brands, pricing, sizes, and availability, driven by backend API queries.
* **Interactive Shopping Cart & Wishlist:** Client-side state management for adding items, managing quantities, and saving favorites.
* **Secure Admin Dashboard UI:** Protected interface for administrators to view real-time order logs and update product stock.
* **Asynchronous API Integration:** Clean service layer handling HTTP requests, global loading states, and error alerts.

## 🛠️ Tech Stack

* **Framework:** React.js
* **Styling:** Tailwind CSS (or CSS modules)
* **State Management / Routing:** React Router (and Context API / Redux if applied)
* **HTTP Client:** Axios / Fetch API

## ⚙️ Local Development Setup

To run the frontend client locally:

1. Clone this repository.
2. Install dependencies: `npm install`
3. Start the development server: `npm start` (or `npm run dev`)
